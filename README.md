# Chatbot IA — Showcase

## Demo funcional

Aplicación web que permite a los negocios gestionar sus servicios y consultar información de su propia documentación mediante un asistente basado en IA.

🎥 **[Ver demostración en Loom](https://www.loom.com/share/37ba23832ebd41e688d65f797c998cde)**

https://www.loom.com/share/37ba23832ebd41e688d65f797c998cde

## Funcionalidades demostradas

- Gestión de negocios y servicios.
- Consulta de información del catálogo.
- Incorporación y procesamiento de documentos.
- Recuperación de información documental mediante RAG.
- Respuestas con referencias a los documentos utilizados.

## Stack tecnológico

- Java 21
- Spring Boot
- PostgreSQL
- pgvector
- Ollama
- Next.js
- TypeScript

## Estado del proyecto

Proyecto personal en desarrollo. La demostración muestra funcionalidades implementadas y verificadas. La calidad de la recuperación semántica y la fiabilidad de las respuestas continúan en fase de mejora.
